# Инструкции для агентов

## О проекте

- `vkpw` — Python CLI и библиотека для авторизации VK ID через Playwright и сохранения минимального набора cookies сессии.
- Поддерживаемая версия Python: 3.10 и новее. Следуйте существующему стилю и сохраняйте совместимость с Python 3.10.
- Основные модули находятся в `src/vkpw/`, тесты — в `tests/`.

## Браузер и данные пользователя

- Всегда запускайте браузер Playwright в headless-режиме. Не добавляйте headed-режим, флаги для показа окна или автоматическое переключение режима в зависимости от ОС.
- Можно запускать уже установленный Chromium, Chrome, Edge или Brave, но только в новом временном профиле Playwright.
- Никогда не подключайтесь к уже запущенному браузеру и не используйте постоянный профиль (`launch_persistent_context`, пользовательский `user-data-dir` или аналогичные механизмы).
- Не импортируйте и не загружайте cookies, local storage, cache, историю, расширения, proxy-настройки или иные данные из профиля пользователя. Контекст авторизации должен создаваться чистым; добавляйте только данные, которые нужны самой библиотеке и заданы явно.
- При закрытии браузера временный контекст должен завершаться вместе с ним. Не сохраняйте состояние браузера между запусками.

## Безопасность и авторизация

- Не обходите CAPTCHA, одноразовые коды и другие проверки VK. Сообщайте о необходимости дополнительной проверки понятной ошибкой.
- Не выводите и не записывайте в логи пароль, cookies, access token или другие секреты.
- Сохраняйте только cookies, необходимые для совместимости (`p` и `remixsid`), и не меняйте существующий формат файла без необходимости.
- Сохраняйте текущую атомарность записи и защиту файла с cookies.

## Проверки

- После изменений запускайте тесты: `uv run python -m unittest discover -s tests -v`.
- Для изменений CLI проверьте справку: `uv run vkpw --help`.
- Если меняется браузерный запуск или работа с профилем, добавьте или обновите тесты, подтверждающие headless-запуск и отсутствие повторного использования состояния пользователя.
