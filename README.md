# vkpw

CLI-утилита для получения cookies сессии **ВКонтакте (vk.ru)** через обычную браузерную форму VK ID: логин и пароль вводятся на странице VK, а не отправляются самописным скриптом входа.

`vkpw` старается использовать уже установленный Chromium, Google Chrome, Microsoft Edge или Brave. Скачивать отдельный браузер нужно только если на компьютере не найден подходящий движок.

## Установка как CLI tool

```console
uv tool install "git+https://github.com/matrixd0t/vkpw.git"
vkpw -o cookies.json
```

Разовый запуск без постоянной установки:

```console
uvx --from "git+https://github.com/matrixd0t/vkpw.git" vkpw -o cookies.json
```

Аналогичный разовый запуск через `pipx`:

```console
pipx run --spec "git+https://github.com/matrixd0t/vkpw.git" vkpw -o cookies.json
```

Постоянная установка через `pipx`:

```console
pipx install "git+https://github.com/matrixd0t/vkpw.git"
vkpw -o cookies.json
```

Для разработки из клона репозитория:

```console
uv tool install --editable .
vkpw -o cookies.json
```

В `uv 0.13.4` команда установки инструментов называется `uv tool install`; `uv tool add` в этой версии отсутствует.

## Использование

```console
vkpw -o cookies.json
```

Утилита запросит логин и пароль. Пароль вводится скрыто и не принимается параметром командной строки, поэтому он не попадёт в историю команд. Если `-o` не задан, путь к JSON-файлу запрашивается после успешной авторизации.

Пример:

```text
$ vkpw -o cookies.json
Логин VK (телефон или почта): +7...
Пароль VK:
OK: user_id=123456789, cookies сохранены в .../cookies.json
```

### Выбор браузера

- По умолчанию ищутся Chromium, Chrome, Edge и Brave в стандартных местах установки и в `PATH`.
- Можно указать конкретный исполняемый файл: `vkpw --browser-path /path/to/chrome -o cookies.json`.
- Браузер всегда запускается в headless-режиме и во временном чистом профиле Playwright. Cookies, кеш и другие данные профиля обычного браузера пользователя не читаются и не изменяются.
- Если совместимого браузера нет, установите управляемый Chromium командой `vkpw install-browser`. Эта команда скачивает браузер Playwright; она нужна только как запасной вариант.

Firefox и Safari напрямую не запускаются: для воспроизводимого управления VK ID используется Chromium-протокол Playwright. Существующие Chrome, Edge, Brave и Chromium повторно используются без загрузки второго браузера.

## CAPTCHA и дополнительные подтверждения

Утилита не распознаёт и не обходит CAPTCHA, подтверждение входа или одноразовый код. Браузер всегда работает без окна, поэтому при запросе такой проверки утилита завершится с понятной ошибкой. Пройдите проверку отдельно и повторите вход.

Пользовательский интерфейс VK ID может меняться, поэтому для входа используются доступные названия элементов и поля формы, а не координаты кликов.

## Формат JSON

Формат совместим с `vkqr` и читается `vkx`:

```json
{
  "cookies": [
    {
      "created_at": 1700000000,
      "user_id": 123456789,
      "p": "...",
      "remixsid": "..."
    }
  ]
}
```

- Успешная сессия проверяется через веб-токен VK и `users.get`; без корректного `user_id` файл не меняется.
- В существующий файл новая запись добавляется в конец `cookies`; старые аккаунты и дополнительные поля, например `_vkx`, сохраняются.
- Запись содержит только обязательные для сессии `p` и `remixsid`, `user_id` и `created_at`.
- Сохранение атомарное. На Unix-файловых системах итоговый файл получает права `600`.

Использование с `vkx`:

```python
from vkx import VKClient

vk = VKClient(cookies="cookies.json")
```

## Безопасность

`p` и `remixsid` дают доступ к аккаунту. Не коммитьте JSON с cookies, ограничьте к нему доступ и не передавайте файл третьим лицам. `vkpw` не сохраняет пароль и не печатает значения cookies.
